\# To-Do API



.NET Minimal API ile geliştirilmiş basit bir yapılacaklar listesi (To-Do) API'si.



\## 🚀 Teknolojiler



\- C#

\- .NET 10

\- ASP.NET Core Minimal API

\- Swagger (Swashbuckle)



\## 📋 Özellikler



\- Tüm görevleri listeleme (GET)

\- Tek görev getirme (GET)

\- Yeni görev ekleme (POST)

\- Görev güncelleme (PUT)

\- Görev silme (DELETE)



\## 🔗 API Endpoint'leri



| Metod | Endpoint | Açıklama |

|-------|----------|----------|

| GET | /api/todos | Tüm görevleri listeler |

| GET | /api/todos/{id} | Belirli bir görevi getirir |

| POST | /api/todos | Yeni görev ekler |

| PUT | /api/todos/{id} | Görevi günceller |

| DELETE | /api/todos/{id} | Görevi siler |



\## ⚙️ Çalıştırma



```bash

dotnet run

```



Ardından tarayıcıda http://localhost:PORT/swagger adresini açarak API'yi test edebilirsiniz.
